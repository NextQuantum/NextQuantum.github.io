Android companion

EasyPi protection and private services on your phone

EasyPi Mobile links an Android 11+ phone to your home EasyPi with a one-time QR code. A restricted Mobile API token and pinned HTTPS connection keep remote management separate from full-device VPN traffic.

🛡️

PRISM Protection

Applies authenticated EasyPi domain policy locally to DNS and TLS SNI traffic.

🥷

Chameleon VPN

Routes all traffic or selected apps through Chameleon, independently from PRISM.

🖼️

Photos and sharing

Syncs a chosen photo folder and accepts Android Share actions for private uploads to EasyPi.

📹

Dashboard and cameras

Shows this phone's DNS protection statistics and snapshots from cameras connected to EasyPi.

🔐

Tokens and the Chameleon profile are encrypted with Android Keystore. The app uses no Accessibility service, does not inspect the screen, disables cleartext traffic, and keeps Mobile Link available while the VPN reconnects.

Architecture

How EasyPi is connected

The browser and EasyPi Mobile talk to one protected control plane. Only reviewed tasks cross the privileged boundary, while networking and VPS services stay in clearly separated paths.

STEALTH TRANSPORT

Chameleon

Single-hop traffic protection that resembles ordinary HTTPS.

  • nginx cover on TCP 443 with the backend kept on loopback
  • XChaCha20-Poly1305, HKDF-SHA256, and anti-replay controls
  • Strict DNS and a fail-closed firewall kill-switch
ADAPTIVE NETWORK ANALYSIS

PRISM

Guard Security learns normal traffic and reviews new signals before enforcement.

  • FlowGraph, TLS Lineage Gate, and Counterfactual Flow Lab
  • Shadow Mode observes candidate decisions safely
  • Heuristics combine DNS, device, timing, and traffic evidence

Get Started

Install a verified release

Official target: Raspberry Pi OS Lite 64-bit, Debian Trixie, ARM64. Verify the publisher signature before privileged installation.

📋 Requirements

  • 🍓 ARM64 Raspberry Pi (Pi 4 with 4GB RAM or better recommended)
  • 💿 Raspberry Pi OS Lite 64-bit based on Debian Trixie
  • 💾 32GB+ storage with additional space for models, backups, and recordings
  • 🌐 Internet connection

🚀 Installation

EasyPi uses a detached RSA/SHA-256 signature. The trust key must come from an independently authenticated channel.

Terminal — Signed Release Installation
$ easypi-install-release \ --archive-url "https://release.example/easypi-full-aarch64-trixie.tar.gz" \ --signature-url "https://release.example/easypi-full-aarch64-trixie.tar.gz.sig"
✓ Signature verified → archive validated → transactional install
Setup: Follow the on-screen wizard to create your admin account.

A checksum detects corruption; it does not authenticate the publisher. The detached signature is the release trust gate.
